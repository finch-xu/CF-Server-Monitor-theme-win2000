## 0. 调研结论：必须遵守的约束

来源：官方 [`theme-develop.md`](https://github.com/huilang-me/CF-Server-Monitor/blob/main/theme-develop.md)、上游 `src/handlers/frontend.js`、`src/utils/csp.js`、主题商店 [`CFSM-Theme-Store`](https://github.com/huilang-me/CFSM-Theme-Store) 的 `scripts/build-themes.sh`。

| 约束 | 对设计的影响 |
| --- | --- |
| 构建产物只能是 `index.html` + `assets/` | Vite 输出到 `dist/`；商店脚本执行 `npm run build` 后拷贝 `dist/`；Worker 从 GitHub raw 读取指定分支的 `index.html` 与 `/assets/*`，并会把 `./assets/` 改写成 `/assets/` |
| 旗帜 `/flags/<code>.svg`、OS 图标 `/os-icons/<file>` 走默认皮肤 | 不打包这两类图标；主题内的其他图标全部自绘 |
| 标题、favicon、背景图、自定义 `<head>` / 脚本由后台注入 | 不写死；后台背景图会被注入成 `body` 背景 → 「桌面」层必须透明，只有没设背景图时才显示桌面色 |
| CSP：`script/style-src 'self' 'unsafe-inline'`，`font-src 'self' fonts.gstatic.com`，`connect-src 'self' + API` | 所有资源本地打包，不引 CDN；只用系统字体栈 |
| 底部必须展示 `Powered by CF-Server-Monitor` + 链接，建议带 `version` | 放在资源管理器状态栏、桌面右下角水印、「关于」对话框三处 |
| 路由：`/#/`、`/#/server/:id`；管理入口只能跳 `/admin#admin` | Hash 路由；「开始 → 管理后台」和「注销」都跳 `/admin#admin` |
| 主题不可用时要暴露错误，不能静默跳转 | 致命错误用「蓝屏」页展示详细错误 + 重试按钮 |
| 首页：`/api/servers` → `wss /api/ws?subscribe=all` → 发送 `{type:'subscribe',scope:'all',ids}` | 多 `apiBase` 时每个后端各建一条 WS，`ids` 只放该后端的服务器 |
| 详情页：`/api/server?id=` + `wss ?subscribe=<id>`，禁止拉全量 | 详情页数据流独立 |
| `visibilitychange` 时断开/恢复 WS，恢复前先补一次 REST | 页面隐藏 → 任务栏托盘网络图标变灰 |
| `frontend_ws_timeout_minutes > 0` 时到点断开，由用户决定是否继续 | 经典 MessageBox「是 / 否」 |
| 非公开站点需要 JWT；跨域时 WS 走 `?token=` | 复用上游 `localStorage.jwt_token` 约定；登录由内置后台完成 |
| Turnstile（`turnstile_enabled`） | 在「正在启动」画面里弹出一个经典对话框承载 Turnstile 组件 |
| 未登录时 `hours > 24` 返回 401 | 历史范围下拉框中 48h / 96h / 7 天 置灰，并带工具提示「需要登录」 |
| `ping_*` / `loss_*`：`false` = 不显示，`null` = 超时，`0` = 有效值 | 三网延迟展示严格按这个语义实现 |
| `disk` 对象缺失时不展示磁盘 IO；`gpu_info` 可能是字符串或数组 | 选项卡按数据是否存在动态显示 |
| `sysConfig.show_price / show_expire / show_tf / show_three_net_details` | 控制价格、到期、流量、三网小图是否出现 |
| `theme_options`：`/api/config` 读取，`POST /api/theme_options`（需 JWT）写入 | 用于「显示 属性」里的站点默认外观设置 |

## 1. 设计理念：把整个页面做成一台 Windows 2000 电脑

不是「灰色配色的仪表盘」，而是**完整的桌面隐喻**：访客打开页面 → 看到启动画面 → 进入桌面 → 资源管理器窗口里是服务器列表 → 双击一台服务器打开它的「任务管理器」。每个监控功能都对应一个 Windows 2000 用户熟悉的东西：

| 监控功能 | Windows 2000 中的对应物 |
| --- | --- |
| 服务器列表首页 | 资源管理器窗口「我的服务器」 |
| 卡片 / 圆环 / 表格 / 地图视图 | 「查看」菜单：大图标 / 属性饼图 / 详细信息 / 网上邻居 |
| 按分组 / 地区 / 标签筛选 | 左侧「文件夹」树 + 地址栏路径 `我的服务器\按地区\日本` |
| 搜索服务器 | 工具栏「搜索」 + 开始菜单「查找」 |
| 排序 | 详细信息视图的列头（带 ▲▼） |
| 选中服务器的摘要 | Win2000 特有的「Web 视图」左侧信息栏（含磁盘饼图） |
| 全局统计（在线数、总流量、实时速率） | 状态栏分栏 + Web 视图信息栏 |
| 剩余价值 / 汇率 | 「费用 属性」对话框（属性页 + 列表） |
| 服务器详情页 | 「服务器任务管理器 - HK-01」窗口，含性能 / 联网 / 磁盘 / GPU / 系统信息选项卡 |
| CPU / 内存实时数值 | 任务管理器的绿色 LED 柱状表 |
| 历史曲线 | 黑底绿网格的「使用记录」图 |
| 历史时间范围 | 「历史范围」下拉框（对应「查看 → 更新速度」菜单） |
| WebSocket 连接状态 | 托盘「本地连接」双屏图标（收到数据时闪烁） |
| 服务器上线 / 离线通知 | 托盘气球提示（Win2000 首次引入） |
| 语言切换（中/英） | 托盘输入法指示器 `CH` / `EN` |
| WS 超时询问 | 带 ⚠ 图标的 MessageBox「是(Y) / 否(N)」 |
| CORS / 接口错误 | 带红色 ✕ 图标的错误对话框 |
| 致命加载失败 | 蓝屏 `*** STOP: 0x00000401 (API_UNAUTHORIZED)` |
| 首次加载 | 启动画面 + 分段进度条 + 沙漏光标 |
| 主题设置 | 「显示 属性」对话框（背景 / 屏幕保护程序 / 外观 / 效果） |
| 深色模式 | 「高对比度」外观方案 |
| 离线服务器 | 桌面「离线服务器」图标（回收站样式） |
| 管理后台 | 开始菜单「管理后台...」 → `/admin#admin` |

## 2. 视觉规范

### 2.1 颜色（经典标准方案）

| 用途 | 值 |
| --- | --- |
| 按钮表面 / 窗口底色 | `#D4D0C8`（Win2000 暖灰，区别于 Win98 的 `#C0C0C0`） |
| 高光 / 亮面 | `#FFFFFF` |
| 阴影 | `#808080` |
| 暗阴影 | `#404040` |
| 活动标题栏渐变 | `#0A246A → #A6CAF0` |
| 非活动标题栏渐变 | `#808080 → #C0C0C0`，文字 `#D4D0C8` |
| 选中项 | 底色 `#0A246A`，文字 `#FFFFFF` |
| 桌面 | `#3A6EA5` |
| 工具提示 / 气球 | `#FFFFE1` + 1px 黑边 |
| 超链接 | `#0000FF`，悬停 `#FF0000` |
| 禁用文字 | `#808080`，带 1px 白色投影（凹刻效果） |
| 分段进度条 | `#0A246A` 方块；占用 ≥ 80% 时改为 `#A00000`（主题新增的告警色） |
| 磁盘饼图 | 已用 `#0000FF` / 可用 `#FF00FF`（侧面加深为 `#00006A` / `#7A007A`） |
| 性能图 | 黑底，网格 `#008040`，CPU `#00FF00`，内存 `#FFFF00`，Swap `#00FFFF` |

所有颜色都写成 CSS 变量，外观方案只切换变量。

### 2.2 立体边框配方（全部用 `border` + `box-shadow` 实现，零图片）

- **凸起（按钮）**：`border-color: #fff #404040 #404040 #fff; box-shadow: inset -1px -1px #808080, inset 1px 1px #D4D0C8`
- **窗口外框**：`border-color: #D4D0C8 #404040 #404040 #D4D0C8; box-shadow: inset 1px 1px #fff, inset -1px -1px #808080`
- **凹陷（输入框、列表）**：`border-color: #808080 #fff #fff #808080; box-shadow: inset 1px 1px #404040, inset -1px -1px #D4D0C8`
- **细凹陷（状态栏分栏）**：只保留一层 `#808080 / #fff`
- **蚀刻分组框**：`border: 1px solid #808080; box-shadow: 1px 1px 0 #fff, inset 1px 1px 0 #fff`，标题压在边框上
- **按下的任务栏按钮**：凹陷 + `#fff / #D4D0C8` 2×2 棋盘抖动底纹
- **默认按钮**：多一圈 1px 黑框；获得焦点时文字外有 1px 点线框

### 2.3 字体与尺寸

- 字体栈：`Tahoma, "SimSun", "宋体", "Microsoft YaHei", sans-serif`。中文 Win2000 的界面字体就是 9pt 宋体，Windows 访客能看到最还原的点阵效果；其他系统自动回退。
- 基础字号 12px（≈ 8/9pt），标题栏 11px 粗体；不打包任何字体文件（许可 + 体积两方面考虑）。
- **除气球提示外一律不用圆角**；图标加 `image-rendering: pixelated`，SVG 加 `shape-rendering: crispEdges`。
- 标准尺寸：标题栏 18px，标题栏按钮 16×14，菜单栏 20px，按钮 75×23，任务栏 28px，状态栏 20px。

### 2.4 图标

全部**原创**像素风 SVG（16 / 32px 两套），不使用 Microsoft 原版图标：我的服务器（显示器）、服务器地图（地球）、离线服务器（回收站样式）、文件夹、命令提示符、任务管理器、搜索、历史、刷新、警告 / 错误 / 信息图标等。「开始」按钮使用自绘的「云 + 心电线」标志，**不使用 Windows 四色旗**。

### 2.5 滚动条与光标

- 滚动条：`::-webkit-scrollbar` 实现带箭头按钮和抖动轨道的经典样式；Firefox 用 `scrollbar-color: #D4D0C8 #eee` 回退。
- 光标：默认箭头；加载时 `cursor: progress`，可选自绘的像素沙漏光标（`assets/` 内的 `.cur`/`.png`）。

## 3. 页面结构

### 3.1 桌面、任务栏、开始菜单（全局外壳）

- **桌面**：左侧一列图标——我的服务器、服务器地图、离线服务器 (N)、命令提示符（彩蛋）。单击选中（蓝底 + 点线框），双击打开。右下角白字水印：`Powered by CF-Server-Monitor v2.8.5`（致敬 Win2000 评估版水印）。
- **任务栏**（固定底部）：
  - 「开始」按钮
  - 快速启动：显示桌面、服务器地图、命令提示符
  - 窗口按钮：每个打开的窗口一个，当前窗口为按下的抖动底纹样式
  - 托盘（凹陷区）：WS 状态图标（连接中闪烁 / 断开变灰 / 出错红叉，悬停显示「已连接 2/2 个站点，每 2 秒更新」）、`CH`/`EN` 语言切换、时钟（悬停显示日期工具提示）
- **开始菜单**：左侧竖排渐变条写 `CF-Server-Monitor` + 版本号，菜单项：
  - 服务器(P) ▶ 按分组级联到每台服务器（带在线指示灯和 CPU%）
  - 最近查看(D) ▶ 最近打开过的详情页（localStorage）
  - 设置(S) ▶ 显示属性 / 语言 / 控制面板
  - 查找(C)... → 搜索对话框
  - 帮助(H) → 关于对话框（版本、Powered by、主题仓库链接）
  - 运行(R)... → 输入服务器名直接跳转
  - 管理后台(A)... → `/admin#admin`
  - 断开实时连接(U)... → 仿「关闭 Windows」对话框：断开实时连接 / 重新载入数据 / 进入管理后台

### 3.2 首页 = 资源管理器窗口（`/#/`）

从上到下：

1. **标题栏**：`我的服务器 - {site_title}`，最小化 / 最大化 / 关闭。「关闭」首页窗口时桌面仍在，双击桌面图标可重新打开。
2. **菜单栏**（可用、有下拉、带下划线快捷键，支持 Alt+字母）：
   - 文件：打开、属性、关闭
   - 查看：工具栏 / 状态栏 / 文件夹窗格 开关；**卡片 / 圆环 / 列表 / 详细信息 / 地图**（单选）；排列图标 ▶ 按名称 / CPU / 内存 / 流量 / 到期；刷新
   - 收藏：把服务器加入收藏（localStorage），收藏的服务器出现在「收藏」菜单和文件夹树中
   - 工具：费用明细（剩余价值）、显示属性
   - 帮助：关于
3. **工具栏**：后退、前进、向上 ｜ 搜索、文件夹、历史 ｜ 视图 ▾、刷新；右侧「排序」下拉框。
4. **地址栏**：显示当前筛选路径，如 `我的服务器\按地区\日本`；下拉可快速切换。
5. **主体**：
   - 左：可开关的「文件夹」树——我的服务器 → 按分组 / 按地区（带国旗）/ 标签 → 服务器地图、离线服务器。点树节点 = 设置筛选。
   - 中：Win2000「Web 视图」信息栏（窗口够宽时显示）——大图标 + 标题 + 渐变分隔线；选中服务器时显示它的系统、地区、运行时间、到期、价格和**磁盘 3D 饼图**；下半部分是全站统计（在线/离线、总流量、实时速率、剩余价值「查看费用明细...」）。
   - 右：内容区，随「查看」模式切换：

| 视图 | 样式 |
| --- | --- |
| **卡片**（大图标） | 每台服务器是一个迷你窗口：标题栏 = 状态灯 + 名称 + 地区代码（**离线服务器用非活动的灰色标题栏**）；内容为系统 / 运行时间、CPU / 内存 / 硬盘 / 流量四条分段进度条、实时网速、到期天数（≤ 7 天标红） |
| **圆环** | 「属性」对话框样式，每台服务器 3 个蓝/洋红 3D 饼图（CPU、内存、硬盘） |
| **列表** | 16px 小图标 + 名称 + 状态文字，多列紧凑排列，适合上百台服务器 |
| **详细信息** | ListView 表格：凸起列头可点击排序、可拖动列宽；选中行深蓝底；单元格内嵌迷你分段进度条；离线行灰字；双击打开详情 |
| **地图** | 「网上邻居」窗口里一张原创像素风世界地图（灵感来自 Win2000「日期/时间 属性 → 时区」地图），有服务器的国家/地区高亮，悬停显示工具提示，点击 = 按地区筛选 |

   分组：卡片 / 圆环视图按 `server_group` 分节，节标题为粗体文字 + 右侧细分隔线（与 Win XP「分组显示」类似）。

6. **状态栏**（分栏凹陷）：`8 个对象（已选定 1 个）` ｜ `在线 6 / 离线 2` ｜ `↓ 5.41 MB/s ↑ 1.92 MB/s` ｜ `Powered by CF-Server-Monitor v2.8.5` ｜ 实时连接状态 ｜ 右下角缩放手柄。

### 3.3 详情页 = 服务器任务管理器（`/#/server/:id`）

打开时首页资源管理器仍在后面（标题栏变为非活动灰色），任务管理器窗口在前。关闭窗口 = 返回 `/#/`。

数据规则（遵守官方「详情页不要拉全量、不要订阅 all」）：

- 从首页进入：关闭首页的 `subscribe=all` 连接，背后的资源管理器保留最后一次数据**静态显示**（状态栏显示「已暂停」）；详情页只用 `/api/server?id=` + `subscribe=<id>`。返回首页时先补一次 `/api/servers`，再恢复 `subscribe=all`。
- 直接打开详情链接：**不加载**资源管理器数据，任务栏里显示为最小化的「我的服务器」按钮，点击它才回到首页并开始加载列表。

- 标题：`服务器任务管理器 - {name}`；菜单：文件 / 选项（总在最前、更新速度）/ 查看 / 帮助。
- 选项卡上方右侧：「历史范围」下拉框（实时、10 分钟、30 分钟、1 小时、6 小时、12 小时、24 小时、48 小时、4 天、7 天，对应接口的 `hours` 可选值；未登录时 >24h 置灰）+「< 返回列表」按钮。

| 选项卡 | 内容 |
| --- | --- |
| **性能** | 左列 LED 表（CPU %、内存用量），右列黑底绿网格使用记录图（CPU；内存 + Swap）；下方网络流量图（↓ 绿 / ↑ 黄，左侧刻度）；底部四个分组框：总数（进程 / TCP / UDP）、物理内存（总数 / 已用 / 可用）、交换空间、系统负载（1/5/15 分钟）。完全对应 Win2000 任务管理器「性能」页的布局 |
| **联网** | 借用 Win XP 任务管理器的「联网」页：网络带宽图 + 三网（CT / CU / CM / BGP 及自定义 Node 1–4）延迟曲线与丢包；下方 ListView 列出每条线路的当前延迟、丢包、状态（`null` 显示「请求超时」，`false` 不显示） |
| **磁盘** | 3D 磁盘饼图（已用 / 可用）+ 磁盘 IO 图（读写速率、IOPS、await、util）；无 `disk` 数据时只显示饼图 |
| **GPU** | 仅在有 `gpu_info` 时出现：使用率、显存、频率、功耗曲线 |
| **系统信息** | 仿「系统 属性 → 常规」页：OS、内核、架构、CPU 型号 × 核数、GPU、IPv4/IPv6、运行时间、启动时间、上次上报；另有「计费」分组：价格 / 周期 / 自动续费 / 到期 / 流量额度 / 重置日 / 本月已用（受 `sysConfig` 开关控制） |

- 状态栏：`进程数: 312` ｜ `CPU 使用: 68%` ｜ `内存使用: 5.8 GB / 8 GB` ｜ `实时 · 每 2 秒更新 · 上次上报 1 秒前`。
- 图表交互：悬停出现竖直点线 + 黄色工具提示（时间 + 数值）；实时模式下曲线从右向左滚动，和原版任务管理器一样。

### 3.4 对话框与反馈

- **MessageBox**：信息 / 警告 / 错误 / 询问四种图标；默认按钮加黑框；Esc = 取消；Enter = 默认按钮。
- **气球提示**：服务器从在线变离线（或恢复）时从托盘弹出，5 秒后自动消失；可在「显示 属性 → 效果」里关闭。
- **工具提示**：`#FFFFE1` 黄底，悬停 500ms 后淡入（Win2000 引入的淡入效果）。
- **启动画面**：黑底，原创标志 + `CF-Server-Monitor · Classic 2000 Theme` + 分段蓝色进度条 +「正在连接 2 个站点 · 已加载 1/2」。多站点加载时进度真实反映。
- **蓝屏**：仅用于致命错误（所有站点都拿不到配置 / 服务器列表）。显示 `STOP` 代码（用 HTTP 状态码）、请求 URL、可读原因和处理建议（401 → 登录 `/admin#admin`；CORS → 检查 `CORS_ALLOWED_ORIGINS` / `apiBase`；409 → 提示管理员升级数据库）；按任意键或点击重试。**绝不静默跳转。**
- **部分失败**（多站点中某个站点失败）：不蓝屏，只弹错误 MessageBox，其余站点正常显示。

### 3.5 显示 属性（主题设置）

入口：桌面右键菜单「属性」、开始 → 设置、工具 → 显示属性。

| 选项卡 | 设置项 |
| --- | --- |
| 背景 | 桌面颜色；原创像素图案（无 / 砖墙 / 网格 / 波纹…）；「使用站点背景图」（后台配置了背景图时默认开启） |
| 屏幕保护程序 | 无 / 字幕（横向滚动服务器状态）/ 飞越星空；等待时间；「屏保运行时暂停实时连接」（节省额度，恢复时先补 REST 再重连） |
| 外观 | 方案：经典标准、高对比度（深色）、沙漠、云杉、茄子、Windows 98 蓝绿；「跟随站点默认外观（`preferred_theme`）」 |
| 效果 | 菜单 / 工具提示淡入、窗口最小化动画、拖动时显示窗口内容（否则只拖轮廓框）、声音（WebAudio 合成的提示音，默认关闭） |
| 布局 | 默认视图、卡片密度、Web 视图信息栏开关、分组方式 |

- 访客的个人设置存 `localStorage`。
- **管理员登录状态下**（存在 `jwt_token`）多一个按钮「设为站点默认值」，调用 `POST /api/theme_options` 保存；其他访客加载 `/api/config.theme_options` 作为默认。
- `preferred_theme`：`dark` → 高对比度方案，`light` → 经典标准，`auto` → 跟随 `prefers-color-scheme`。

### 3.6 彩蛋（可选，M3）

- **命令提示符**：`help`、`dir [/offline]`、`ping <服务器>`（显示三网延迟）、`systeminfo <服务器>`、`netstat`（全局速率）、`cls`、`ver`、`exit`。首行写明「本主题为开源项目，与 Microsoft 无关」。
- **事件查看器**：记录本次会话中的上线 / 离线 / 连接断开事件，带信息 / 警告 / 错误图标。

## 6. 技术方案

### 6.1 技术栈

- **Vue 3 + Vite + vue-router（hash 模式）**：与上游一致，方便对照上游实现，产物也小。
- **不引入 UI 库**：手写一套经典控件组件和 CSS。参考 98.css 的做法，但 Win2000 的配色（`#D4D0C8`）、字体（Tahoma / 宋体）和细节与之不同，手写更准确，也更好配合外观方案切换。
- **图表：自绘 Canvas 2D**（约 300 行）。任务管理器风格只需要折线 + 网格 + 悬停提示，自绘最容易做到滚动效果和像素级还原，也省掉 Chart.js 的体积。如后续需要缩放拖拽等复杂交互，再换更轻量的 uPlot。
- **地图**：Natural Earth（公有领域）简化世界地图 SVG，按 `regionStats` 着色，打包进 `assets/`。
- **数据层**：按官方文档自行实现，参考上游 MIT 许可代码（`http.js`、`api.js`、`finance.js`、`i18n.js` 的逻辑），在文件头保留来源和版权声明。

### 6.3 关键实现要点

- **实时数据**：`sample.data || sample.payload || sample.metrics` 增量合并到服务器对象；高频样本进环形缓冲区，实时曲线直接读取；UI 更新按 `requestAnimationFrame` 合批，避免上百台服务器时卡顿。
- **在线判定**：与上游一致，最后上报时间超过 5 分钟视为离线；状态变化时触发气球提示。
- **窗口管理器**：z-index 栈 + 活动窗口；拖动用 Pointer Events；最小化到任务栏；位置 / 大小存 `sessionStorage`。
- **无障碍**：所有控件用原生 `<button>` / `<input>`；菜单支持方向键与 Alt 快捷键；焦点点线框；`prefers-reduced-motion` 时关闭所有动画。
- **国际化**：中 / 英两套文案（菜单快捷键字母也随语言变化），`default_language` 决定默认值。

### 6.4 开发、构建与发布

- 本地开发：`npm run dev`，通过 `.env` 里的 `VITE_API_BASE` 代理到自己的 Worker；Worker 的 `CORS_ALLOWED_ORIGINS` 加入 `https://localhost:5173`。
- `npm run build` → `dist/index.html` + `dist/assets/`（`base: './'`）。
- GitHub Actions：推送 `main` 时构建，把 `dist/` 推到 `build` 分支。
- 纯静态部署：`npm run build:github-page`，读取 `.env` 的 `API_BASE`、`TITLE`、`BACKGROUND_IMAGE`、`CSP_API`、`CSP_STATIC`。
- 发布到主题商店：向 `huilang-me/CFSM-Theme-Store` 提 PR，在 `themes.json` 中新增条目（`id`、`title`、`cover`、`tags`、中英 `description`、`url`、`branch: "build"`、`author`、`versions[{version, commitid}]`）。
