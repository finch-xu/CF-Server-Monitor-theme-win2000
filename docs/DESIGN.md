# Win2000 风格主题设计方案

> CF-Server-Monitor 第三方主题
>
> 状态：设计稿（尚未开始编码）
> 视觉稿（私有链接）：https://claude.ai/artifact/PfpkW3UTn9XzY4nSZUohfH

## 1. 原则

- **只换外观，不加功能。** 功能与默认主题一一对应，只把界面换成 Windows 2000 经典风格：灰色立体控件、蓝色渐变标题栏、分段进度条、宋体/Tahoma 小字。
- **整个页面就是一个窗口。** 页面背景是桌面色（或后台配置的背景图），上面只有一个窗口，所有内容都在这个窗口里。没有任务栏、开始菜单、桌面图标这类与监控无关的东西。
- 首页和详情页是同一个窗口，只切换窗口里的内容和标题栏文字。

## 2. 窗口结构

```
┌ 标题栏：图标 + 站点标题                 [中/EN] [明暗] [管理后台] ┐
├ 工具栏：视图切换（首页）/ 返回 + 历史范围（详情页）                 ┤
│                                                                      │
│  内容区                                                              │
│                                                                      │
├ 状态栏：连接状态 │ 版本号 │ Powered by CF-Server-Monitor           ┤
└──────────────────────────────────────────────────────────────────────┘
```

- **标题栏**：左边是站点标题（`site_title`，详情页为「服务器名 - 站点标题」）；右边三个标题栏样式的小按钮，对应默认主题页头的三个控件：语言切换、明暗外观切换、管理后台入口（`/admin#admin`）。不放无用的最小化 / 最大化按钮。
- **状态栏**：满足官方要求的 `Powered by CF-Server-Monitor` 链接和版本号；有新版本时版本号旁显示提示（与默认主题一致，仅登录后有数据）。
- 窗口宽度：大屏最多约 1400px 居中，四周露出一圈背景；窗口高度随内容增长，页面整体滚动。手机上窗口铺满屏幕，去掉四周边距。

## 3. 各部分样式（对应默认主题的功能）

### 首页

| 默认主题功能 | Win2000 样式 |
| --- | --- |
| 卡片 / 圆环 / 表格 / 地图切换 | 工具栏按钮，选中的按钮为按下状态（凹陷 + 抖动底纹） |
| 地区筛选（含「更多」） | 选项卡（Tab）：全部 / HK 香港 2 / JP 日本 1 …，放不下的收进最后一个「更多 ▾」下拉 |
| 全局统计 4 项 | 4 个分组框（蚀刻边框 + 标题压在边框上）；「剩余价值」可点击打开对话框 |
| 按分组显示 | 每个 `server_group` 一个大分组框，标题为「分组名 [数量]」 |
| 服务器卡片 | 迷你窗口：标题栏 = 旗帜 + 名称 + 在线状态（**离线时标题栏变成灰色非活动样式**）；内容为系统、价格 / 到期、标签和 IPv4/IPv6 小徽章、CPU / 内存 / 硬盘 / 流量分段进度条、负载、网速、月流量，底部白色凹陷区显示三网延迟和小方格历史 |
| 圆环视图 | Win2000 磁盘属性风格的 3D 饼图（已用蓝色 / 可用洋红色） |
| 表格视图 | 经典列表控件：凸起的列头、选中行深蓝底白字、单元格内嵌迷你进度条、离线行灰字 |
| 地图视图 | 地图放在凹陷边框里，有服务器的地区用深蓝色标出，提示框为黄底 |
| 空状态 / 加载更多站点 | 普通文字 + 分段进度条 |

### 详情页

| 默认主题功能 | Win2000 样式 |
| --- | --- |
| 返回按钮、时间范围 | 工具栏：「← 返回」+ 分隔线 + 时间范围按钮组；未登录时超过 24 小时的选项显示为灰字，点击后弹出「需要登录」对话框（与默认主题一致） |
| 主机信息 | 「主机信息」分组框：名称 + 在线状态，下面是白色凹陷区里的 4 列信息表 |
| 各项图表（CPU、内存、网络、负载、硬盘、磁盘 IO、GPU、进程、连接、延迟、丢包） | 每个图表一个分组框，标题压在边框上，右上角当前数值 + 展开按钮；图表为 Win2000 任务管理器配色：黑底、绿色网格、亮绿 / 黄 / 青色曲线 |
| 登录提示 | 经典对话框 |

### 对话框（均为默认主题已有的弹窗）

剩余价值与汇率、实时连接超时询问、跨域错误、需要登录：统一为 Win2000 对话框，包括蓝色标题栏 + 关闭按钮、左侧 32px 图标（警告 / 错误 / 信息）、默认按钮带黑色外框、背后是半透明遮罩。

### 加载与错误

- 加载中：窗口里显示「正在加载...」和分段进度条。
- 加载失败：显示错误对话框和具体原因（401 → 提示去 `/admin#admin` 登录；跨域 → 提示检查 `CORS_ALLOWED_ORIGINS`；409 → 提示升级数据库），带「重试」按钮。按官方要求把错误直接显示出来，不跳转。

## 4. 视觉规范

### 浅色（经典标准，默认）

| 用途 | 颜色 |
| --- | --- |
| 页面背景（桌面色） | `#3A6EA5` |
| 窗口 / 按钮表面 | `#D4D0C8` |
| 亮边 / 阴影 / 暗阴影 | `#FFFFFF` / `#808080` / `#404040` |
| 标题栏渐变 | `#0A246A → #A6CAF0`（非活动：`#808080 → #C0C0C0`） |
| 选中项、进度条 | `#0A246A` |
| 告警（≥ 80%、即将到期） | `#A00000` |
| 在线 / 离线指示 | `#00B000` / `#C00000` |
| 工具提示 | `#FFFFE1` + 1px 黑边 |
| 链接 | `#0000FF` |
| 图表 | 黑底，网格 `#008040`，曲线 `#00FF00` / `#FFFF00` / `#00FFFF` |

### 深色

保持完全相同的立体结构，只换一套颜色：背景 `#1B2B40`，表面 `#3C3C3C`，亮边 `#6A6A6A`，阴影 `#202020` / `#0E0E0E`，文字 `#E8E8E8`，输入区 `#1E1E1E`，进度条 `#4A8AF0`，标题栏 `#0A246A → #3A6EA5`。明暗切换沿用默认主题的 auto / dark / light 逻辑，默认值来自 `preferred_theme`。

### 立体边框（全部用 CSS 实现，不用图片）

- 凸起（按钮、窗口）：左上白、右下深灰，外加一层内阴影
- 凹陷（输入区、表格、进度条槽）：与凸起相反
- 分组框：`#808080` 线 + 白色投影形成的蚀刻线
- 按下的工具栏按钮：凹陷 + 白灰棋盘抖动底纹

### 字体与细节

- 字体：`Tahoma, "SimSun", "宋体", "Microsoft YaHei", sans-serif`，12px；不打包字体文件。
- 除标签页的上角外不用圆角；滚动条做成经典灰色带箭头样式（Chrome / Edge / Safari），Firefox 用颜色近似。
- 图标只用官方提供的旗帜（`/flags/`）和系统图标（`/os-icons/`），另外只自绘少量必要的小图标（视图切换、返回、对话框图标），不使用微软的图片素材。

## 5. 技术方案

- **Vue 3 + Vite + vue-router（hash 模式）**：与默认主题一致，功能逻辑可以直接对照默认主题实现。
- **Chart.js**：与默认主题相同，只改配色和网格样式。
- **Leaflet**：地图视图，与默认主题相同，改成经典配色；依赖通过 npm 打包，不从默认皮肤的 `/files/` 读取。
- **样式**：手写 CSS，颜色全部用 CSS 变量，深浅两套变量切换；不引入 UI 库。
- **数据层**：按官方文档实现，包括：`/api/config`、`/api/servers`、`/api/server`、`/api/history/all`、WebSocket 订阅、多 `apiBase`、Turnstile、JWT、页面隐藏时断开 WS、超时询问、延迟值 `false` / `null` / `0` 的区别、`sysConfig` 各显示开关。参考默认主题中 MIT 许可的代码，保留版权声明。
- **构建**：`npm run build` 输出 `dist/index.html` + `dist/assets/`；GitHub Actions 把产物推到 `build` 分支供主题商店使用；另外提供 `npm run build:github-page` 用于纯静态部署。

## 6. 开发步骤

1. 搭脚手架，写好配色变量和立体边框样式，做好窗口外壳（标题栏、工具栏、状态栏）。
2. 数据层与实时连接。
3. 首页：统计分组框、地区选项卡、卡片视图、表格视图。
4. 详情页：主机信息与全部图表。
5. 圆环视图、地图视图、各个对话框、深色外观、中英文、手机适配。
6. 构建流水线、预览图，提交主题商店。
